

## Per-Action Completion Process

For every discrete task action needed to complete the user's request, apply
this complete process before moving to another action:

1. Identify the current task-relevant input, target, and acceptance point.
2. Scope the action to the exact output or task area that currently needs work.
3. Perform that one task-relevant creation, revision, or transformation.
4. Check the resulting artifact against the relevant local task requirement.
5. Decide from the user task and actual artifact state whether to repair this
   action, select the next task-relevant action, or finish because all requested
   deliverables are complete.

Repeat this process for each further task-relevant action. Keep the decisions
in the current context only: do not create a workflow board, packet, lease,
checkpoint, marker, handoff record, or proof round. Once the requested
deliverables are complete and appropriately checked, finish normally.
