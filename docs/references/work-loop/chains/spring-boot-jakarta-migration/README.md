# Spring Boot Jakarta Migration

This directory contains a five-skill migration workflow. The candidate manifest
defines the skill order, task objective, and expected handoff markers.

- `skills/spring-boot-jakarta-migration-entry-upgrade/SKILL.md`
- `skills/spring-boot-jakarta-migration-namespace/SKILL.md`
- `skills/spring-boot-jakarta-migration-security-hibernate/SKILL.md`
- `skills/spring-boot-jakarta-migration-restclient-verification/SKILL.md`
- `skills/spring-boot-jakarta-migration-continuation-gate/SKILL.md`

Use the reference replay entry point to validate the assets or execute the chain
with an external SkillsBench checkout and an explicit provider configuration.
